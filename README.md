# SherloCAN

**Automotive Network Investigator**

SherloCAN is an evidence-first automotive CAN diagnostic platform.

Current development target: **v0.2 Capture & Investigate**.

Core principle:

> OBSERVE → RECORD → CORRELATE → TEST → EXPLAIN

The project starts read-only: capture, replay, baseline comparison, event markers and anomaly investigation. Unknown vehicle data stays UNKNOWN until documented or measured.
